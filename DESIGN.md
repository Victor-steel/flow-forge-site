# Flow Forge — DESIGN.md

Local agency marketing site for UK trades and small businesses.

## Design read

Persuade landing for busy owners. Forge vernacular from the logo: charcoal, amber flame, warm workshop paper. Not SaaS purple, not cream-serif-terracotta.

## Tokens

| Token | Value |
| --- | --- |
| Canvas | `#0a0b0d` (full-page charcoal, logo ground) |
| Surface | `#14161c` / `#1c1e26` elevated bands |
| Ink | `#f4efe8` |
| Amber CTA | `#e8953a` |
| Ember hover | `#ff6a3d` |
| Display | Syne 700/800 |
| Body | Public Sans 400/500/600 |

## Rules

- Brand name is hero-level in the first viewport
- Square corners on controls
- One chromatic accent (amber) for CTAs and markers
- Motion: hero rise + scroll reveals; respect `prefers-reduced-motion`
- Locked contacts and prices stay accurate — never invent testimonials
